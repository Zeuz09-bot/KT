# Design Reference Directory (Stitch Exports)

> **Purpose**: This directory houses visual assets, screenshots, UI mockups, and exported design screens from Google Stitch (or design tooling).

---

## Guidelines for AI Agents:
1. **Reference Only**: Treat all files in this directory as read-only visual specifications.
2. **Do Not Overwrite or Delete**: Never modify, delete, or rename image files in this directory unless explicitly instructed by the user.
3. **High Fidelity**: When implementing UI components, inspect and match:
   - Layout hierarchies and component composition
   - Color palettes, typography, and contrast
   - Padding, margins, border radii, and drop shadows
   - Responsive adaptations across viewports
