# Custom Agent Rules (`.agent/rules/`)

This directory contains modular rule files that Antigravity automatically discovers and injects into agent context.

## Usage
- Add `.md` files in this directory for domain-specific rules (e.g., `coding-standards.md`, `git-conventions.md`, `security.md`).
- Rules here supplement the root `AGENTS.md`.
- Both `.agent/` and `.agents/` directory paths are recognized across different Antigravity versions.
