# Workflows & Custom Slash Commands (`.agent/workflows/`)

This directory contains executable workflows and custom slash commands for Antigravity.

## How Workflows Work
- Each Markdown file in this directory maps directly to a slash command (e.g., `preflight.md` can be invoked as `/preflight`).
- Workflows specify multi-step instructions, automated command chains, or verification sequences for the agent to run reliably.
